# Roadmap

## Milestone 0 - Project Foundations
- Confirm scope, success metrics, and evaluation rubric.
- Finalize target stack (Python, Streamlit, vector DB).
- Curate initial NASA and ESA document list.
- Define JSON contracts for agent communication.

## Milestone 1 - Ingestion and Vision
- Implement image upload pipeline and storage.
- Add preprocessing and metadata extraction.
- Integrate Gemini Vision classification.
- Capture baseline telemetry for each run.

## Milestone 2 - RAG Baseline
- Build ingestion pipeline for NASA/ESA documents.
- Create embedding and vector store indexing.
- Implement retrieval and re-ranking.
- Establish relevance evaluation set.

## Milestone 3 - Multi-Agent Orchestration
- Implement Vision, Research, Science Writer agents.
- Add Evaluator agent and quality scoring.
- Orchestrate end-to-end flow with traceability.

## Milestone 4 - Reporting and Exports
- Design report templates and output formats.
- Implement citation formatting and evidence linking.
- Generate scientific report artifacts.

## Milestone 5 - Streamlit Dashboard
- Build Home and Upload pages with run history.
- Add Reports and RAG Explorer views.
- Implement Planet Explorer comparison module.
- Add Telemetry and evaluation summaries.

## Milestone 6 - Validation and Hardening
- Validate outputs against scientific sources.
- Add safety checks and monitoring thresholds.
- Document limitations and known gaps.
